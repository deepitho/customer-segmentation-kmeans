customer-segmentation-kmeans
Customer Segmentation using K-Means Clustering in Python

This project performs customer segmentation using machine learning.
Tools Used
Python
Pandas
Matplotlib
Seaborn
Scikit-learn

Steps Performed
Data loading and preprocessing
Exploratory Data Analysis
Elbow Method for optimal clusters
K-Means clustering
Customer segment visualization

Result
Customers were divided into 5 segments based on Annual Income and Spending Score.
